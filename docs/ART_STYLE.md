# 絵のきまり（CAT-WARS の シール・バッジ・はた）

2026-11-16。シール・バッジ・基地の はた は、ぜんぶ この きまりで SVG を手で書く（外の画像生成は使わない）。
**全部で1つの絵柄に見えること**がいちばん大事。足すときも この きまりに そろえる。

## 置き場所と名前

| もの | 置き場所 | 名前 |
|---|---|---|
| シール | `public/assets/stickers/` | `<シールの id>.svg`（例 `st-fish.svg`） |
| バッジの絵柄 | `public/assets/badges/` | `<バッジの id>.svg`（例 `run.svg`・`unit-area.svg`） |
| バッジの わく（メダルの台） | `public/assets/badges/` | `frame-bronze.svg`・`frame-silver.svg`・`frame-gold.svg`・`frame-solo.svg` |
| 基地の はた | `public/assets/flags/` | `<はたの id>.svg`（例 `flag-paw.svg`） |

- **同じ名前で上書きしない**（端末に古い絵が残ることがある）。描きなおすときは `st-fish-2.svg` のように新しい名前で足し、`stickers.ts` などの `image` を書きかえる。
- 組みこみ：シールは `catwars/collection/stickers.ts` の `image`、バッジは `badges.ts` の `image`（`BADGE_ART`）、はたは `titles.ts` の `image`。
  出す側（`components/collection/CollectionParts.tsx` の `ArtImg`）は `<img>`。読めなかったら 絵文字に もどる。
- ネコ・ボス・施設の PNG を使っている シールは そのまま（PNG を使いつづける）。

## 形

- `viewBox="0 0 128 128"`・背景は透過。まんなかに大きく（余白は上下左右 10〜14）。はたは 横長 2:1 の旗を 128 の正方形の中に ポールつきで描く。
- 48px で出しても 何の絵か分かる シルエットにする。細かすぎる線を入れない。
- かわいく・やさしく（こわい・気持ちわるい絵にしない）。顔を付けるときは いまのネコの絵と同じ「大きな丸い目（白い光の点つき）・小さな口・ピンクのほっぺ」。
- 文字（`<text>`）・フォント・`filter`・`mask`・外の画像・スクリプトは使わない。`clipPath` と `<use>` は使ってよい。
- 1ファイル 4KB 以下（座標は小数1けたまで）。

## 線

- りんかく線：こい紺 `#1e1b4b`、太さ 5、`stroke-linejoin="round"` `stroke-linecap="round"`（ルートの `<svg>` に書いて 下に引きつぐ）。
- 中の線（もよう・目もり・しわ）：太さ 3（口は 2.5〜3）。

## 色（パレット 12色＋それぞれの影の色）

| 名前 | 色 | 影（下がわ・こいめ） |
|---|---|---|
| 紺（りんかく・目） | `#1e1b4b` | — |
| 白 | `#ffffff` | `#cbd5e1` |
| 灰 | `#e2e8f0` | `#94a3b8` |
| 黄 | `#fde047` | `#eab308` |
| だいだい | `#fb923c` | `#ea580c` |
| 赤 | `#f87171` | `#dc2626` |
| ピンク | `#f9a8d4` | `#ec4899` |
| むらさき | `#a78bfa` | `#7c3aed` |
| 青 | `#60a5fa` | `#2563eb` |
| 水色 | `#67e8f9` | `#0891b2` |
| みどり | `#4ade80` | `#16a34a` |
| ちゃ | `#d6a35c` | `#a16207` |

- 1まいに 3〜5色のベタぬり。
- **影は1段だけ**：その形の中に、同じ形を 左上へ (−4, −7) ずらした 元の色を重ね、右下に こいめの色が 三日月のように のこる（`clipPath` で形の中だけ）。
- **ハイライト**：白（`opacity .7`）の だ円や まるを 1〜2こ、左上に。
- グラデーションは使わない（使うなら 2色の線形を1つまで）。

## シール

- 絵の外がわに 白いふち（ダイカット）：同じ形を `fill="#fff" stroke="#fff" stroke-width="14"` で下に敷く（りんかく線の外に 白が 約4.5 見える。10 だと 48px で ほとんど見えなかったので 14 にした）。
- めずらしさは 絵では描き分けない。わくの色（`frame`）と、レア以上は CSS の光（`index.css` の `.cw-glow`。ゆっくり光る・`prefers-reduced-motion` では止める）で見せる。

## バッジ

- メダルの台（わく）は 絵柄とは別の SVG（`frame-*.svg`）。段で色がかわる：銅 `#b45309` 系・銀 `#94a3b8` 系・金 `#eab308` 系・1段だけのバッジは 紺と水色。
- 絵柄は台の まんなかに 62% の大きさで重ねる（`BadgeMedal`）。絵柄には 白いふちを付けない。
- まだ取っていないバッジは CSS の filter で 灰色のシルエット（台は灰色）。かくしバッジは 取るまで「？」。
- 単元のバッジは その単元の道具（÷・ます目・分数の円・立方体 など）＋ 右下に 小さな水色の 💎（かけら）。

## はた

- 横長 2:1 の旗が 左のポールに付いて、右に ゆるく なびく。旗の色は `titles.ts` の `colors` と そろえる。
