# CAT-WARS 作り直しの仕様（2026-11-15〜）

実装を引きつぐ人（別のセッション・別のモデル）のための、**決めたこと・数値・合格条件**。
経緯と根拠は知識集 `onokomachi-master-DB` の `techspecs/catwars-rebuild-plan-and-status.md`。
古い設計メモ `docs/CATWARS_DESIGN.md` の経済（自動収入）・陣地（当日リセット）の節は、この仕様が上書きする。

## 0. ゆずれない方針
1. **問題を解くことがゲームを動かす。** 解かずに進める道を作らない（待つ・放置・連打で進まない）。
2. 問題は **SOL の単元アプリと同じ問題・同じ答え方**（`apps/`・`catwars/learn/gradePack.ts`）。1回目のまちがいで×。まちがえても罰はない。
3. **速さを報酬にしない。** 報酬と星は「まちがえずに解けたか」で決める（急いで雑に解くことを得にしない）。
4. 個人の順位表は作らない（学級の合計・自分の記録で見せる）。
5. ガチャ的な要素は SANMON の決まり：確率を画面に出す・天井あり・学習の成果でしか回せない・集めきってもごほうびなし（コンプガチャにしない）。
6. トップ層（1日に長時間）とエンジョイ勢の両方が楽しめる：**上限のない深さ**（難易度・収集・育成）と、**少しでも進む浅さ**（1戦3〜5分・負けても育つ）。
7. 学年はパックで足す（ゲーム本体に4年の単元名を書かない）。

## 1. 戦闘の経済（CW-2・実装ずみ）
- 自動収入なし（`energyPerSec: 0`）。はじめのエナジーは `PLAYER_START_ENERGY = 60`（基本のネコ2回ぶん）。
- エナジーは **問題カード**（`ProblemCards.tsx`）から。手札3枚（やさしい・ふつう・むずかしい）。基準 `QUIZ_BASE_REWARD = 150` × むずかしさの重み（0.75〜1.45）× 連続（×1.0〜2.0）。
- 解いている間、戦闘は止まる。敵をたおした分のエナジー（少額）は残す。
- 星：`starsFor(answered, perfect)`。★3＝8問以上で9割、★2＝5問以上で7割、勝てば★1。
- **合格条件**（`npm run test:balance`。数値を変えたら必ず流す）：
  - 「とかない」（1問も解かない想定プレイヤー）が **全章で勝率0%**
  - 「ふつう」が勝った試合で解いた問題が **平均18問以下**
  - 「にがて」の勝率が 目標±15ポイント（章1〜2：85%／3〜6：70%／7〜8：55%）
- 想定プレイヤー（`scripts/botSim.ts`）：正答率（0.92／0.78／0.58）・人の操作の速さ（2.0／3.0／4.5秒に1手）・エナジーが足りないときに解く。

## 2. 敵・難易度・やりこみ（CW-3）
- **難易度3段**：各章に ふつう／むずかしい／げきむず。むずかしい＝敵HP×1.35・敵の出現×1.25・敵の基地の配置を変える。げきむず＝HP×1.8・出現×1.5・新しい敵が出る。星は難易度ごと（1章で最大9つ）。
- **脅威レベル**：`threat = round(0.9 × max(0, 手持ちの平均レベル − 章の基準レベル))`。敵のHP・こうげきを `1 + 0.06 × threat` 倍（上限 +120%）。SANMON の `scaledOpponentLevel` と同じ考え方。育てすぎても楽勝にならない。画面に「脅威 Lv.n」を出す（隠れた調整はしない）。
- **新しい敵**（編成を変えないと勝てない）：盾持ち（正面のダメージ半減・魔法に弱い）／回復役（まわりを回復・先にたおす）／自爆（建物に大ダメージ・遠距離でたおす）／空中（飛行・遠距離でないと当たらない）。
- **ボスのシールド**：ボスは シールド（HPの外側）を持つ。**その子の「復習の時期が来た項目」（ポータルの `next_due_ts`。つなぐ前は まちがえた項目）の問題を解くと割れる**。割らないとダメージが1割しか通らない。
- **合格条件**：全章×3難易度で、にがての勝率が目標帯（ふつう：上の表／むずかしい：−15／げきむず：−30）。脅威レベルあり・なしで、Lv差20の手持ちの勝率の差が15ポイント以内。とかない＝0%。

## 3. 基地・育成・収集（CW-4）
- **基地は永続**：施設（コア・兵舎・砲台・電撃トラップ・キャンプ・発電所（旧 金山））に Lv1〜10。上げるのは クレジット（💠。問題と勝利でたまる）。
  その日に動かすには「きょうの学習」が要る：きょう まちがえずに解いた数 ÷ 5 ＝ 動かせる施設の数（上限 全部）。休んでも施設は消えない。
- **編成**：出撃は5枠。8系統＋解放したネコから選ぶ。敵の構成（章の画面に出す）に合わせて組む。
- **育成**：レベルは戦闘と問題で上がる。**上限は単元の「かけら」**（kit の `sanmonShards`。上限＝20＋5×かけら・60まで）。
  **スキル**（系統ごとに3つ）は、その系統に結びつけた単元の熟達で開く（例：魔法系＝分数・小数、タンク系＝わり算の筆算）。対応は学年パックに書く。
- **収集**（SANMON に見劣りしないこと）：
  - **図鑑**：ネコ（系統×3段階）＋敵＋ボス。出会う・たおす・仲間にする で埋まる。コンプリートの割合を出す
  - **バッジ**：章の星（27×難易度）、単元ごとの「100問 まちがえずに」、連続日数、全系統を進化、げきむず全クリア など。**学習の量と質にだけ**出す（放置・課金・運では出ない）
  - **シール**：SANMON と同じ決まりのカプセル（確率表示・10回で天井・学習の成果のコインだけ）。シール＝図鑑の絵
  - **称号・基地のかざり**：バッジの数で開く（見た目だけ。強さは変わらない）
- **用語**：他社ゲームの固有名を置きかえる（タウンホール→コア、エリクサー→エナジー、バーバリアン系の内部ID以外の表示名、隠しテスラ→電撃トラップ（済）、アーミーキャンプ→キャンプ、金山→発電所）。内部IDは変えない（セーブの互換は不要だが、差分を小さくするため）。
- **合格条件**：1日20分のエンジョイ勢が4週間で第8章（ふつう）に届く／1日90分のトップ層が8週間たっても「次の目標」が残っている（げきむず・バッジ・図鑑の未達が3割以上）。これは 想定の進み方を計算するスクリプト（`scripts/progressionSim.ts` を作る）で確かめる。

## 4. ポータル接続（CW-5）
- kit を入れる（`init standalone` ではなく、SANMON と同じ形：JoinGate・`fetchSanmonStatus`・`spendStamina`）。
- **スタミナは SANMON と共通**。出撃1回＝5（サーバが決める）。えらんだ単元の町のスタミナ → 共通 の順。reason は `catwars@<町の key>`。
- サーバ：モードの鍵 `catwars` を足す（kit の `SANMON_MODES`・サーバの `_sanmon_effective_modes`・平日モードの対象・番号ごとの停止）。セーブは新しい表 `catwars_save`（`sanmon_save` と同じ形）。
  **SQL は持ち主が SQL Editor で流す**（試験用（最後に `raise exception` で結果を出して取り消す）→ 本番の2段階。知識集の patterns 参照）。
- 記録：戦闘中に解いた問題は `learning_event` に送る（app_id は `catwars`、skill_id は単元アプリの skill_id、module_id は町の key）。
  **スタミナには数えない**（SANMON の「バトルの中の答えは数えない」と同じ。遊ぶほどスタミナが戻る、を防ぐ）。PRISM では CAT-WARS の単元として見える。
- PRISM：SANMON タブのモードの開け閉めに CAT-WARS を足す。**SOL の一覧にはまだ出さない**（`apps` に足すとき `default_open = false`・SOL 側で非表示）。
- おためし・デモ・体験版は SANMON と同じ扱い（名乗らないと記録を送らない・セーブは別）。

## 5. 遠征・対戦（CW-6）
- **週がわりの遠征**：毎週月曜に、種（seed）とルール（例：空中の敵だけ・霧で射程−1・敵の出現2倍）が変わる。学級の合計スコア（星の合計）で目標を目指す。個人の順位は出さない。
- **同時対戦（本命）**：決定的な戦闘の計算（`catwars/sim/`）とロックステップ（`catwars/net/lockstep.ts`）を Supabase Realtime Broadcast に載せかえる（`net/transport.ts` の実装を1つ足す）。
  対戦のエナジーも問題から（2人に同じ問題カードを配る）。SANMON のクラス対戦と同じく、部屋・スタミナ・勝ち負けの記録はサーバ。
- **基地を攻めあう**：友だちの基地の配置（サーバに保存）に、CPU が守る形で攻めこむ。相手は同時にいなくてよい。
